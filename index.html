Sincronización onlinesin conectar

Guarda una copia de los datos de este dispositivo en tu propio repositorio de GitHub (en un archivo sync/datos.json), para poder traerla a otro equipo o móvil. No hace falta contratar ningún servidor: se usa tu cuenta de GitHub.

El token se crea en GitHub → Settings → Developer settings → Fine-grained tokens, dándole permiso de Contents: Read and write sólo en este repositorio. Se guarda únicamente en este dispositivo, nunca se sube a ningún sitio.

Al traer, lo de la nube y lo de aquí se combinan sin perder tomas.

Bucle: los pasos que se repiten en cada ciclo (una bolsa, una pieza…). El cronómetro gira por ellos sin parar.
Inicio: se hacen una vez al empezar cada lote. Cierre: una vez al terminarlo, cuando pulsas Cerrar lote.
El recorrido es: inicio → bucle, bucle, bucle… → cierre → inicio del lote siguiente.
Deja las uds por toma en blanco para usar el valor por defecto del grupo (arriba a la derecha).
Guardar y recuperar

Todo se guarda solo según cronometras y se conserva al cerrar la pestaña. Este botón es solo para confirmarlo.

La copia .json es un extra para archivar o migrar: solo se descarga cuando tú lo pides.

Cómo se usa

Cada actividad guarda sus propios pasos y sus propias tomas. Cambiar de actividad no mezcla nada.

Si reordenas o renombras un paso, las tomas ya registradas siguen pegadas a ese paso: no se descolocan.

Al borrar un paso que tiene tomas, se borran también sus tomas, y te lo pregunta antes.
